# Atlas HR — Employee Registration

Day 1, Task 2. A responsive employee registration form: Employee ID, Full Name, Email, Mobile, Department, Designation, Date of Joining, Password/Confirm Password, with Register and Reset buttons. Two-column layout on desktop, single-column on mobile.

## Folder structure

```
Task-2/
├── index.html
├── css/
│   └── style.css
└── assets/
    ├── images/
    │   └── logo.svg
    ├── icons/
    └── fonts/
```

## Connects to

- **Back to Home** → `../Task-1/index.html`
- **Already registered? Login** → `../Task-3-Bharath/login.html`

## Running locally

Open `index.html` with a local server such as VS Code's Live Server extension.
