# Atlas HR — Employee Directory

Day 2, Task 2. A searchable, filterable employee directory. Local JavaScript array (no backend/API), search by name, filter by department, responsive card grid.

## Connects to

The sidebar now shows the full 11-module list (Dashboard, HR Dashboard, Employee Directory, Employee Management, Employee Profile, Attendance, Leave Request, Leave Approval, Payroll, CRM, Finance) - same as every other module page in this project. This page marks itself active for Employee Directory, and links out to the live version of every other module (e.g. Employee Management → `../Task-6-Bharath/employee-management.html`).

- Superseded by **Task-8-Bharath**, which adds Search, Filter and Sort

## Running locally

Open `index.html` (or `employees.html` directly) with a local server such as VS Code's Live Server extension.
